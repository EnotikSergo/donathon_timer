## Возможности

- Отсчёт с паузой, горячими клавишами и сохранением при закрытии программы.
- Донаты DonationAlerts, DonateX и Boosty добавляют время по заданной цене за час, подписки и продления Boosty — по цене уровня.
- Сбор на цель: донаты копятся до суммы на N часов, затем часы добавляются разом.
- Автоповышение цены каждые 3 дня таймера или секундомера, можно выключить.
- Режим сна: таймер идёт в 2 раза медленнее.
- Секундомер «прошло …» и надпись с ценой, которую можно двигать и масштабировать.
- Оверлей для OBS, PRISM т.д. чтобы была возможность по ссылке применять его.

## Горячие клавиши

Работают в окне таймера.

| Клавиша | Действие |
|---|---|
| `Space` | пауза / продолжить |
| `↑` / `↓` | добавить / убрать минуту |
| `Shift` + `↑` / `↓` | добавить / убрать час |
| `R` | сбросить таймер на 5 часов |
| `O` | открыть / закрыть панель управления |

## Подключение донатов

Откройте панель управления клавишей `O`. Справа блок «Авторизация».

### DonationAlerts

1. Выберите «DonationAlerts» и нажмите **«Запросить токен»**.
2. В открывшемся браузере войдите в DonationAlerts и разрешите доступ приложению.
3. Когда появится «Авторизация успешна!», закройте вкладку: токен вставится и применится сам.

Если в статусе написано «Запросите токен заново», повторите эти шаги. Так бывает, если доступ отозван, токен истёк или программа просит новое разрешение, чтобы досчитывать донаты, пропущенные при обрыве связи.

### DonateX

1. Выберите «DonateX» и нажмите **«Запросить токен»**: откроются настройки DonateX.
2. Скопируйте токен из раздела **«Настройки → API и доступ»**.
3. Вставьте его в поле «Токен доступа» и нажмите **«Применить токен»**. Программа проверит токен и покажет ник.

### Boosty

1. Выберите «Boosty» и в поле «Блог Boosty» укажите свой блог (`boosty.to/имя` или просто имя).
2. Нажмите **«Запросить токен»**: откроется окно Boosty внутри программы.
3. Нажмите **«Войти»** (Log in) в правом верхнем углу и войдите в свой аккаунт. Окно закроется само, программа проверит токен и подключится.

Программа проверяет новые донаты и подписки раз в 20 секунд. Донаты добавляют время по сумме, новые подписки и продления — по цене уровня подписки. Донаты и подписки, пришедшие до подключения, не засчитываются.

Окно входа работает со своей отдельной сессией, не связанной с вашим браузером, поэтому вход в программе не мешает пользоваться Boosty в браузере. Если вход через Google или VK в этом окне не проходит, войдите по почте или телефону.

<details>
<summary>Запасной способ: вставить Cookie вручную</summary>

1. Откройте boosty.to в окне инкогнито и войдите.
2. `F12` → **Network** → обновите страницу → первый запрос `boosty.to` → **Request Headers** → скопируйте значение **Cookie** целиком.
3. Вставьте его в поле «Токен доступа», укажите блог и нажмите **«Применить токен»**.
4. Закройте окно инкогнито, не нажимая «Выйти».

Boosty не даёт открытого API, поэтому программа пользуется тем же внутренним API, что и сайт. Если Boosty его изменит, подключение может перестать работать до обновления программы.

### Выход

Кнопка «Выйти из …» удаляет токен выбранного сервиса из программы. Полностью отозвать доступ можно в настройках самого сервиса.

Индикаторы DA, DX и BY внизу панели показывают подключение: зелёный — подключено, красный — ошибка, чёрный — не настроено.

## Панель управления

| Настройка | Что делает |
|---|---|
| Режим сна | таймер идёт в 2 раза медленнее |
| Донат-режим | донаты добавляют время и идёт секундомер |
| Показывать сумму за час | надпись «50р = 3 минуты» под таймером |
| Авто увеличение каждые 3 дня | цена растёт на «Сумму увеличения» за каждые 3 дня таймера или секундомера |
| Сумма за 1 час | базовая цена часа в рублях |
| Часов на цель / Активировать сбор | сбор на N часов: донаты копятся, при достижении цели часы добавляются, излишек уходит во время |

Надпись с ценой можно перетащить мышью и изменить колесом прямо в окне таймера. Положение сохранится и сразу применится в оверлее.

## Оверлей

### OBS

- **Захват окна** программы с фильтром «Хромакей» (фон окна зелёный), или
- **Браузерный источник** с адресом `http://localhost:41701/overlay/` (фон прозрачный).

### PRISM и другие устройства (CloudPub)

Чтобы открыть оверлей не только на этом компьютере, нужен публичный адрес, например через [CloudPub](https://cloudpub.ru):

1. Зарегистрируйтесь и установите CloudPub.
2. Добавьте адрес: всё оставьте по умолчанию, только порт поменяйте на `41701`. При желании задайте короткий поддомен.
3. Скопируйте публичный адрес и добавьте к нему `/overlay/`, например `https://test.cloudpub.ru/overlay/`. Вставьте его в веб-источник PRISM или откройте в браузере для проверки.

![Настройка CloudPub, шаг 1](<guide/Настройка в CloudPub.png>)
![Настройка CloudPub, шаг 2](<guide/Настройка в CloudPub_2.png>)

Через CloudPub доступен только оверлей, и только для просмотра. Вход в аккаунты и управление таймером оттуда недоступны.

Устройства в той же сети (без CloudPub) могут открыть оверлей по адресу `http://<IP-компьютера>:41701/overlay/`. При первом запуске Windows может спросить разрешение для сети — разрешите доступ для частных сетей.
